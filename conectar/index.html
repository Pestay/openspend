Conecta tu asistente

Registra y consulta tus gastos conversando con Claude, ChatGPT u otro asistente compatible con MCP. No necesitas programar ni API keys: solo pegar una URL e iniciar sesión con tu cuenta de OpenSpend.

URL del servidor MCP

https://…/mcp

Al conectar, el asistente te pedirá iniciar sesión en OpenSpend y aprobar el acceso. Solo verá tus datos.

Claude · web, escritorio y celular

  1. Abre Settings → Connectors y elige Add custom connector.
  2. Nombre OpenSpend y pega la URL de arriba.
  3. Presiona Connect, inicia sesión y elige Permitir.
  4. Queda disponible también en la app del celular.

ChatGPT

  1. Abre Settings → Apps & Connectors (según tu plan, puede requerir activar el modo desarrollador).
  2. Crea un conector nuevo con la URL de arriba y autenticación OAuth.
  3. Inicia sesión y elige Permitir.

Claude Code

  1. En la terminal:
claude mcp add --transport http --scope user openspend https://…/mcp

Luego, dentro de Claude Code: /mcp → openspend → Authenticate.

Otros · Cursor, VS Code, Cline…

Agrega un servidor MCP remoto (HTTP) con esta configuración:

{ "mcpServers": { "openspend": { "url": "https://…/mcp" } } }

El cliente debe soportar login OAuth para servidores MCP.

Prueba con frases como

  • “Hoy gasté 8 lucas en almuerzo y 4.200 en uber”
  • “Ayer pagué Netflix, 9,99 dólares”
  • “Me llegó el sueldo: 1.800.000”
  • “¿Cuánto llevo gastado este mes por categoría?”
  • “El uber de ayer pásalo a Transporte”

Antes de guardar, el asistente te muestra una vista previa para que confirmes o corrijas.

Seguridad

  • El acceso a OpenSpend es solo por invitación.
  • Cada asistente necesita tu aprobación explícita y solo accede a tus datos.
  • Puedes ver y desconectar tus asistentes desde el dashboard, en "Asistentes con acceso".
